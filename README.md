# Uni-GUI WAM

## 📖 项目介绍

UniGUI-WAM 是一种面向 GUI 代理任务的统一世界-动作模型，能够在单一框架内联合建模未来 GUI 状态与可执行动作。不同于仅进行下一步动作预测的方法，UniGUI-WAM 能够通过未来状态预测辅助动作生成，并支持动作推理、向前验证以及联合世界-动作推理等能力。同时，该模型结合轻量级 GUI-WAM 具身适应模型，进一步探索了世界-动作推理能力在机器人控制场景中的迁移。

本项目提供了一套基于api的本地化任务执行demo，包括：

-   GUI 前端交互界面
-   模型推理服务接口
-   Android 设备控制模块
-   ADB 自动化执行环境
-   操作轨迹记录与可视化

用户可以通过自然语言描述任务，系统会根据当前设备截图生成操作动作，并通过
ADB 控制设备完成任务。

# 📱 Android 环境配置

Android设备需打开开发者模式，启动ADB调试功能；
如需使用输入文本功能，需安装APK目录下的ADBkeyboard.apk键盘，并在输入法中启用。

项目已内置 ADB 工具，请确保 `platform-tools` 目录完整。

# ▶️ 使用教程

运行：

``` bash
python gui.py
```

浏览器访问：

``` text
http://127.0.0.1:8123
```

1.  进入前端页面后，等待设备信息加载完成，选择需要执行任务的目标设备。
2.  用户可通过任务模板快速创建基础任务，也可以根据实际需求修改任务内容或完全自定义任务。
3.  配置任务后，可设置 Seed 参数用于控制模型推理过程的随机性，便于任务结果复现。
4.  点击「执行」按钮后，系统会根据任务描述结合当前设备状态进行智能规划，并通过 ADB 控制设备完成相应操作。

任务执行过程中，页面会实时展示当前运行状态、模型生成的 Action 以及执行结果截图。其中，运行状态用于反馈当前任务阶段，Action 用于查看模型当前决策的具体操作，执行结果区域展示设备页面变化及操作可视化效果。
任务完成后，系统会自动保存执行过程中的截图、操作记录及相关结果文件，便于后续分析和任务评估。

# 🎮 使用说明

进入前端页面后：

1.  可以通过任务模板选择基础任务；
2.  可以修改任务内容或输入自定义任务；
3.  最终执行目标以「执行任务」中的内容为准；
4.  点击执行启动任务。

执行过程中会自动保存任务轨迹。

保存目录：

``` text
outputs/
```

示例：

``` text
outputs/
└── task_id/
    ├── step_0.png
    ├── step_1.png
    ├── step_1_action.txt
    ├── step_2_action.txt
    ├── step_1_pred_CLICK.png
    └── step_2_pred_TEXT.png
```

# 🤖 模型说明

本项目模型针对移动端 GUI 操作任务进行训练。

数据来源APP版本：
  应用       版本
  ---------- ------------------------
  bilibili   8.99.0
  小红书     9.34.4.117faa6
  美团       v12.60.406 build552576
  淘宝       v10.62.13
  京东       v15.8.30
  QQ         v9.3.15.38100
  微信       8.0.74
  12306      5.9.6.5
  番茄小说   7.2.9
  腾讯地图   V11.4.1.5964.8

数据集会在后续开源。

当前模型在部分复杂及未覆盖场景下仍存在一定优化空间，建议结合模型能力边界，在适配度较高的应用场景中进行部署，以发挥更佳效果。

为了解决泛化性问题，我们设计了一套 App图结构辅助系统，目前针对部分常用 App 进行了验证性适配，包括：

-   美团
-   小红书
-   哔哩哔哩

经测试，基于此系统可以以较低的成本在其他未训练过的app上(或app经历较大的版本更新后)让
模型拥有泛化性，使模型在无需重新训练的情况下具备一定的跨应用泛化能力。然而，在部分
未经训练的场景下，模型幻觉和鲁棒性问题无法完美解决，后续我们会进行针对性的优化，敬请期待。

模型架构、模型性能评测以及 Baseline 对比结果详见技术报告（暂未发表）。

# ⚠️ 注意事项

1.  建议执行任务前保持设备状态稳定；
2.  推荐在任务执行前将手机设置为 HOME 界面，并切换到需要使用的 App 所在的界面；
3.  使用过程中请关闭系统弹窗、应用小窗、悬浮球等功能，防止模型推理过程中出现弹窗导致点击失败；
