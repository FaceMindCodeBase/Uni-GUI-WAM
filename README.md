# Uni-GUI WAM

## 📖 项目介绍

UniGUI-WAM 是一种面向 GUI 代理任务的统一世界-动作模型，能够在单一框架内联合建模未来 GUI 状态与可执行动作。不同于仅进行下一步动作预测的方法，UniGUI-WAM 能够通过未来状态预测辅助动作生成，并支持动作推理、向前验证以及联合世界-动作推理等能力。同时，该模型结合轻量级 GUI-WAM 具身适应模型，进一步探索了世界-动作推理能力在机器人控制场景中的迁移。

本项目提供了一套基于api的本地化任务执行demo，包括：

-   GUI 前端交互界面
-   模型推理服务接口
-   Android 设备控制模块
-   ADB 自动化执行环境
-   操作轨迹记录与可视化

用户可以通过自然语言描述任务，系统会根据当前设备截图生成操作动作，并通过
ADB 控制设备完成任务。

本项目由 **FaceMind 脸谱心智** 开发。

# 🚀 快速开始

## 环境要求

建议环境：

-   Windows 系统
-   Python 3.10+
-   Android 设备或模拟器
-   ADB 工具

# 📱 Android 环境配置

Android设备需打开开发者模式，启动ADB调试功能；
如需使用输入文本功能，需安装APK目录下的ADBkeyboard.apk键盘，并在输入法中启用。

项目已内置 ADB 工具，请确保 `platform-tools` 目录完整。

------------------------------------------------------------------------

# ▶️ 启动前端

运行：

``` bash
python gui.py
```

浏览器访问：

``` text
http://127.0.0.1:8123
```

# 🎮 使用说明

进入前端页面后：

1.  可以通过任务模板选择基础任务；
2.  可以修改任务内容或输入自定义任务；
3.  最终执行目标以「执行任务」中的内容为准；
4.  点击执行启动任务。

执行过程中会自动保存任务轨迹。

保存目录：

``` text
outputs/
```

示例：

``` text
outputs/
└── task_id/
    ├── step_0.png
    ├── step_1.png
    ├── step_1_action.txt
    ├── step_2_action.txt
    ├── step_1_pred_CLICK.png
    └── step_2_pred_TEXT.png
```

# 🤖 模型说明

本项目模型针对移动端 GUI 操作任务进行训练。

我们的模型在 10 个常用 App 上收集了 120 条完整任务轨迹以及 50 条单步
plan 数据，总条数2000 ，并在自行设计的 Qwen3.5-loop 模型上进行了一轮 SFT 训练。

数据来源APP版本：
  应用       版本
  ---------- ------------------------
  bilibili   8.99.0
  小红书     9.34.4.117faa6
  美团       v12.60.406 build552576
  淘宝       v10.62.13
  京东       v15.8.30
  QQ         v9.3.15.38100
  微信       8.0.74
  12306      5.9.6.5
  番茄小说   7.2.9
  腾讯地图   V11.4.1.5964.8

数据集会在后续开源。

由于训练数据规模较少，模型目前存在泛化性和鲁棒性不足的问题，包括：

-   未覆盖场景下存在模型幻觉；
-   未覆盖场景下决策能力有限。

为了解决泛化性问题，我们设计了一套 App
图结构辅助系统，目前针对部分常用 App 进行了验证性适配，包括：

-   美团
-   小红书
-   哔哩哔哩

经测试，基于此系统可以以较低的成本在其他未训练过的app上(或app经历较大的版本更新后)让
模型拥有泛化性，使模型在无需重新训练的情况下具备一定的跨应用泛化能力。然而，在部分
未经训练的场景下，模型幻觉和鲁棒性问题无法完美解决，后续我们会进行针对性的优化，敬请期待。

模型架构、模型性能评测以及 Baseline 对比结果详见技术报告（暂未发表）。

# ⚠️ 注意事项

1.  建议执行任务前保持设备状态稳定；
2.  推荐在任务执行前将手机设置为 HOME 界面，并切换到需要使用的 App 所在的界面；
3.  使用过程中请关闭系统弹窗、应用小窗、悬浮球等功能，防止模型推理过程中出现弹窗导致点击失败；
